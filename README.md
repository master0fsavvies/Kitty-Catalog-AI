# Kitty Catalog AI

A Python project for organizing and searching media.

## Setup

Install the required dependencies:

pip install -r requirements.txt

## Run

Start the application:

python app.py

## Project Files

- `app.py` — Application entry point.
- `requirements.txt` — Python dependencies.
- `media/` — Media files.
- `tests/` — Project tests.

See `START_HERE.md` for setup details and `README_CONTEXT_UPDATE.md` for additional notes.
